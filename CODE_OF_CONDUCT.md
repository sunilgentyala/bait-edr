# BAIT Project Code of Conduct

## Our commitment

Project participants must communicate respectfully, evaluate technical ideas on their merits, and protect sensitive security information. Harassment, intimidation, personal attacks, discriminatory conduct, and deliberate disclosure of private data are not acceptable.

## Security-specific expectations

Participants must not:

- post credentials, customer data, private endpoint telemetry, or personal information
- upload live malware or exploit payloads to issues or pull requests
- disclose a suspected vulnerability publicly before maintainers can assess it
- encourage unauthorized monitoring, access, containment, or disruption
- misrepresent test results, security assurance, standards conformance, or project affiliation

Use synthetic and sanitized evidence. Follow [SECURITY.md](SECURITY.md) for vulnerability reporting.

## Enforcement

Maintainers may edit or remove content, close contributions, restrict participation, or report platform abuse when conduct creates safety, privacy, legal, or community risk. Enforcement decisions should be documented privately and applied consistently.

## Scope

This code applies to repository issues, pull requests, discussions, project websites, and other spaces officially managed by the BAIT maintainers.
